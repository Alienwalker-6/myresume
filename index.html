CASE FILE // 001

REAL-TIME / MOBILE / WEB / GPS

Aanavandi
Locator.

A real-time KSRTC bus tracking system designed around three interfaces: a passenger mobile app, a driver tracking app, and a depot web platform.

2024 — 2025FLUTTERFIREBASEGPSOPENSTREETMAP
01 // THE PROBLEM

Transit information should arrive before the bus does.

Unpredictable schedules, waiting time, and limited live visibility make public transport harder to plan around. The project focuses on reducing that uncertainty with live location data and a dedicated operational interface.

02 // THE SOLUTION

One live system. Three interfaces.

Drivers publish location data, passengers consume live route information, and depot officers supervise fleet operations through a web platform. Firebase provides the real-time synchronization layer.

05 // ENGINEERING NOTES
  • Real-time tracking: continuous driver-side GPS updates feed the live tracking experience.
  • Passenger access: the passenger application is designed for direct access to route and bus information without authentication.
  • Fleet operations: depot officers can manage buses and bus-stop information through the web platform.
  • Data synchronization: Firebase acts as the cloud backend for live location and operational data.
